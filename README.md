# Hanini Special — Next.js Prototype

نموذج أولي احترافي لمشروع **حنيني سبشل** مبني بـ **Next.js + Contentlayer** مع تجهيز واضح للربط لاحقًا مع **Sanity**.

## ماذا يحتوي المشروع؟
- صفحة رئيسية احترافية ومتجاوبة
- Hero Banner جذاب مع عرض المزايا
- قسم منتجات يقرأ من ملفات JSON عبر Contentlayer
- نموذج طلب خاص للمناسبات يرسل الطلب إلى واتساب بصيغة مرتبة
- قسم آراء العملاء
- روابط تواصل اجتماعي
- زر واتساب عائم أسفل اليسار
- زر صعود للأعلى أسفل اليمين
- تحريكات سلسة باستخدام Framer Motion

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء للنشر
```bash
npm run build
npm run start
```

## النشر على Vercel
1. ارفع المشروع إلى GitHub.
2. اربطه مع Vercel.
3. استخدم الإعدادات الافتراضية.
4. سيتم التعرف على Next.js تلقائيًا.

## أين أعدل المحتوى؟
### المنتجات
داخل:
```bash
content/products/
```

### التقييمات
داخل:
```bash
content/testimonials/
```

### روابط التواصل
داخل:
```bash
content/social/
```

## كيف تنتقل لاحقًا إلى Sanity؟
في هذه النسخة، الواجهة تعتمد على محتوى محلي من JSON عبر Contentlayer.
لاحقًا يمكنك:
1. إنشاء schemas في Sanity لنفس أنواع المحتوى: products / testimonials / socialLinks
2. استبدال استدعاء `allProducts` و `allTestimonials` و `allSocialLinks` باستدعاء من Sanity client
3. الإبقاء على نفس الواجهة تقريبًا بدون تغيير كبير

## ملاحظات مهمة
- استخدمت بيانات مبدئية لأن رابط المحادثة المرفق لم يكن متاحًا بمحتواه العام، لذلك وضعت محتوى أوليًا احترافيًا قابلًا للتعديل بسهولة.
- عدّل أرقام الهاتف وروابط الحسابات وروابط المنصات قبل النشر النهائي.
