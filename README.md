# Hanini Special

نسخة محدثة وجاهزة للاستعراض المحلي أو الرفع على Vercel.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm start
```

## ملاحظات

- هذه النسخة تعمل دون الحاجة إلى مفاتيح Supabase أو Stripe.
- تم إعداد صفحة رئيسية احترافية + صفحة لوحة تحكم أولية للمعاينة.
